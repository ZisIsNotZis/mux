# Mux · 媒体工具 🛠️

> 用于本地媒体合并与拆分的精简 shell 工具。

[English](README.md) · [简体中文](README.zh-CN.md)

## 快速开始

前置条件：Bash 和 `tmux`。请先阅读脚本，然后在本目录运行：

```bash
./split.sh
```

这些脚本是围绕本地媒体工具的**工作流助手**，不是完整媒体库或可移植 API。请先备份重要媒体并确认路径。当前版本为 **0.1.0**（[`VERSION`](VERSION)），变更见 [`CHANGELOG.md`](CHANGELOG.md)。未来会加入参数、依赖检查、dry-run 和常见容器示例。
