# Mux · 媒体工具 🛠️

> 用于本地媒体合并与拆分的精简 shell 工具。

[English](README.md) · [简体中文](README.zh-CN.md)

## 快速开始

运行前请先阅读脚本，再选择对应流程：

```bash
bash app.sh
bash split.sh
```

这些脚本是围绕本地媒体工具的**工作流助手**，不是完整媒体库或可移植 API。请先备份重要媒体，并确认脚本中的输入输出路径。未来会加入参数、依赖检查、dry-run 和常见容器示例。
